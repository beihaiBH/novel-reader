# 📚 小说在线阅读平台 (Online Novel Reading Platform)

一个轻量、开箱即用的 PHP + MySQL 在线小说阅读系统。原生 PHP 编写（无框架依赖），自带阅读器、评论互动、用户体系与积分等级系统，适合个人搭建小说 / 文集 / 长文阅读站。

> 移动端优先设计，支持深色模式、语音朗读、章节进度记忆。

---

## ✨ 功能特性

### 阅读体验
- **章节阅读器**：自动解析 TXT 章节，支持上一章 / 下一章 / 章节跳转
- **阅读设置**：字号、主题（浅色 / 深色 / 护眼）、行距等实时调整并本地记忆
- **字数与阅读时长预估**：每章标题旁显示"本章约 N 字 · 预计阅读 M 分钟"（按 500 字/分钟估算）
- **段落高亮笔记**：长按 / 选中任意文字即可添加高亮与笔记，数据保存在浏览器本地（LocalStorage），无需登录
- **语音朗读 (TTS)**：内置迷你朗读播放器
- **阅读进度记忆**：自动记录上次阅读位置

### 用户与社区
- 注册 / 登录（用户名或邮箱），游客数据可在登录后合并
- 个人主页 / 个人中心，展示等级、积分、阅读时长、追更与收藏
- 评论区：支持盖楼回复、点赞、标签，评论回复 / 点赞邮件通知
- 作品投稿入口

### 积分与等级系统
- **积分获取**：有效阅读（1 分钟 = 1 积分，含防挂机机制）、每日签到、发表书评、收藏书籍
- **签到规则**：每日 +20；连续签到超过 2 天每次 +40；连续满 7 天额外 +150
- **11 级等级体系（Lv0–Lv10）**，前松后紧的成长曲线
- **五阶段视觉主题**：朴素基础 → 黄金尊贵 → 钻石璀璨 → 皇家紫韵 → 神圣流光（Lv10 流光特效），在评论徽章、个人主页、个人中心三处统一呈现

### 管理
- 数据看板（浏览量 / 读者 / 评论 / 追更统计）
- 管理员身份基于管理员用户名判定
- 访问日志记录

## 🛠 技术栈
- 后端：PHP 7.4+ / 8.x（原生，MVC 组织）
- 数据库：MySQL 5.7+ / 8.0（utf8mb4）
- 前端：原生 HTML / CSS / JavaScript（无构建步骤）
- 邮件：PHPMailer（SMTP）

## 🚀 快速安装

### 方式一：图形化安装向导（推荐）
1. 将项目文件上传到网站根目录（如 `/var/www/html/novel/`）。
2. 创建一个空的 MySQL 数据库（或准备好可建库的数据库账号）。
3. 浏览器访问 `http://你的域名/install.php`，按提示填写数据库信息与管理员账号。
4. 安装成功后 **务必删除 `install.php`**。

### 方式二：手动安装
1. 导入数据库结构：
   ```bash
   mysql -u root -p 你的数据库名 < install.sql
   ```
   > `install.sql` 中默认管理员为 `admin / admin123`（首次登录后请立即修改）。
2. 复制并修改配置：编辑 `config/database.php`，填写数据库连接信息。
3. 如需邮件功能，编辑 `mail.php` 填写 SMTP 信息（不需要可留空占位符）。
4. 确保 `avatars/`、`submissions/`、`tts_cache/` 目录可写：
   ```bash
   chmod -R 755 avatars submissions tts_cache
   ```

### 添加小说内容
- 在 `001/`（或新建 `00X/`）目录放入 UTF-8 编码的 TXT 正文文件；
- 章节以「第X章 标题」独立成行作为切分标记；
- 修改对应目录 `index.php` 顶部的 `$file` 指向你的 TXT 文件名即可。
- 项目自带一份 `001/sample.txt` 示例正文，可直接体验。

## 📂 目录结构
```
├── index.php            # 书架首页
├── 001/                 # 示例小说（含 index.php 阅读器 + 示例正文）
├── api.php              # 后端 API 路由
├── config/database.php  # 数据库配置
├── controllers/         # 控制器
├── models/              # 数据模型
├── includes/            # 公共逻辑（积分系统 / helpers）
├── assets/              # 前端资源（app.js / app.css / levels.css ...）
├── phpmailer/           # 邮件库
├── ucenter.php          # 个人中心
├── profile.php          # 个人主页
├── dashboard.php        # 数据看板
├── install.php          # 安装向导（装完请删除）
└── install.sql          # 数据库结构
```
